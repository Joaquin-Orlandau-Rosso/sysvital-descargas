# SysVital

Diagnóstico y mantenimiento de Windows para usuarios comunes: analiza la PC, explica en criollo qué anda mal y aplica solo arreglos seguros (crea un punto de restauración antes).

## Descargar

👉 **[Bajar SysVital 1.13 (ZIP)](https://github.com/Joaquin-Orlandau-Rosso/sysvital-descargas/releases/latest/download/SysVital-1.13.zip)**

## Cómo instalarlo

1. Bajá el ZIP.
2. **Antes de descomprimir:** clic derecho sobre el ZIP → **Propiedades** → tildá **Desbloquear** → Aceptar.
   (Si no, Windows bloquea los archivos porque vienen de internet.)
3. Descomprimilo y abrí **Iniciar SysVital.bat**.
4. Si aparece el cartel azul de Windows ("Windows protegió su PC"): **Más información → Ejecutar de todas formas**. Sale porque el programa no tiene firma digital paga; no es un virus.

Requisitos: Windows 10 22H2 o Windows 11. Más detalles en el `LEEME.txt` que viene adentro.
